# 设置总览

完整设置名称、稳定 ID、搜索别名与页面恢复字段见自动生成的[设置项参考](./settings-reference.md)。

左下角 **菜单 → 设置** 打开主内容整页，一级分类下再选择具体页面，默认进入「常规 → 启动与退出」。设置保留侧栏和原页面，QQ 登录账号管理与 Protobuf / JCE 逆向直接在正文查看，密钥扫描和撤回记录等工具使用遮罩弹窗；数据库修复与 QQNT 抓包使用独立系统窗口。「日志与性能」集中放置自动保存的记录与保存设置，日志和性能监视通过入口分别打开独立窗口。空间页和 WeQ 助手内的局部齿轮复用对应配置。应用锁与隐私模式位于「常规 → 隐私」。设置入口的更新红点只提示增强包；WeQ 本体的更新状态在「关于 WeQ → 版本与更新」查看。

切换设置页面时，离开的界面会卸载，已登记的未保存表单、展开状态与滚动位置保存到本机，回来时重新构建，不再让全部访问过的页面驻留内存。普通返回不重新跳到之前的搜索结果，新的搜索仍会定位对应项目；后台下载、更新等已提交任务继续运行。表单草稿按账号和数据源隔离，不自动提交。点击右上角 × 关闭设置时，有未保存内容会先提醒：选择「继续编辑」保留当前页面与草稿，选择「放弃修改」清除本次设置现场；没有未保存内容则直接关闭。关闭后普通重开回到「常规 → 启动与退出」，从搜索或快捷入口打开仍定位指定页面。离开凭据页、相关令牌页面或锁定应用后，敏感字段重新掩码；验证器绑定在离开页面时取消尚未确认的绑定。

搜索定位设置后，高亮框短暂停留再淡出，约 2 秒后自动消失；再次搜索同一项会重新高亮。启用系统「减少动态效果」时不播放淡出动画，仍会自动清除高亮。

不通过右上角 × 关闭，而是切换设置分类、子页面或进入消息、联系人等主页面时，当前页有未保存内容会先拦截切换。选择「先保存」留在当前页完成保存；选择「暂时离开」继续原来的切换，保留页面路径和未保存内容，返回后可继续编辑。关闭询问框同样留在当前页，不执行切换。已保存的页面直接切换，不重复询问；OneBot 内嵌编辑表单也支持暂时离开后恢复。

| 基础功能 | 会话列表、消息阅读、互动与防撤回、联系人名片、通话与录音、QQ 空间、QQ 邮箱 |
| 增强功能 | 增强包、识别与转写、API 配置、API 用量、推荐回复、意图感知、互动画像、WeQ 助手 |

「媒体来源」并入「资源加载」，外部安卓图片缓存与加载来源、省流量策略在同一页设置。WeQ 账号管理位于「关于 WeQ」，只管理已保存的账号配置。桌面和普通网页的「优先直连 QQ 加载图片」与「Remote 缺少资源时优先直取」可分别开启，默认都关闭。Remote 先复用手机缓存，缺失时可直取 QQ 头像、可用的聊天缩略图、公开名片封面和静态挂件，失败时由电脑加载。省流量模式不直取头像和聊天缩略图；装扮沿用「自动下载个性装扮」。新增素材需要新版 Remote，名片视频、浮屏和需要解包的装扮不变。旧名称和「优先使用 CDN」仍可搜索定位。

Remote 从缓存启动时沿用上一次同步的直取设置，重新连接电脑后同步最新值。更新电脑端 WeQ 后，先让 Remote 连上电脑并打开新版页面一次。之后电脑不可达时，手机能访问 QQ 且省流量模式未生效，就可以直取支持的头像。

通用设置全局保存，切换账号不改变外观、AI、邮箱提醒、防撤回模式、本地装扮、年度报告页面或联系人排序；连接同一电脑的桌面、Web 和 Remote 使用同一份值。会话名单与规则仍属于各自账号及数据源，草稿与分析内容不合并。升级时已有全局值优先，其余以首次打开的当前账号初始化；详见[跨端设置与草稿](./cross-device-settings.md)。

## 软件更新

在桌面主界面打开新版本的官方公告，点击「前往更新」可直达「关于 WeQ → 版本与更新 → 软件更新」，不会自动下载。账号选择页、Web 和 Remote 使用「查看发布页」。升级到该版本后仍能回看公告，不再显示更新按钮。

宿主启动后定时获取官方公告，打开公告时也会按需更新。获取失败会保留已读到的公告，并在列表内提供「重试」。

「关于 WeQ → 版本与更新」提供「检查测试版」开关，默认关闭，并保存到本机应用设置。关闭时只检查正式发布，开启时同时检查正式版和测试版，取版本较新者；纯数字版本但标记为 GitHub 测试发布的版本同样受此开关控制。切换后旧的更新检查结果失效，需重新检查，不会将较旧正式版当作可用更新提示降级。

检查先读取公开发布目录，再对选定版本的加速源进行探测和安装包取样测速；界面显示当前／最新版本与选中的源，下载失败仍按排名切换。测试版下载、Mac 官方包校验及安装沿用同一检查选项，不只改变界面提示。

## 常规与保存

「常规 → 启动与退出」位于第一个二级页面，依次展示开机启动、启动时进入、关闭窗口和主页设置。「开机自动启动」位于最上方；主页设置保留在页面最底部，旧主页入口仍可直接定位。

「启动时进入」可选择主页、消息或上次退出时所在页面，默认进入主页，已有配置保留明确保存的选择。选择主页或消息时，每次重新启动都会从初始状态进入，不恢复各页面的子页面、筛选、选中项和阅读位置；即使上次异常退出，也遵循此选择，设置偏好与未发送草稿保留。选择上次页面时仍还原原栏目与阅读现场。应用进程仍在运行时，界面崩溃重载会接回已打开的账号并恢复现场，不重新应用启动页设置。未自动打开账号时仍先显示账号选择页，打开账号后进入所选栏目。

「常规 → 启动与退出 → 主页」中的个性标签、问候语和一言可独立开关，默认全部开启，标签与一言可以同时显示。偏好全局保存，重启后保留。

「优先展示 QQ 秀」默认开启：本人有 QQ 秀时在主页中央完整等比展示，个性标签仍按原来的圆环围绕形象，不改变标签形状。关闭、没有 QQ 秀或图片加载失败时恢复头像与挂件；加载期间仍显示头像，不等待 QQ 秀才展示主页。此项与聊天中的 QQ 秀头像开关独立，所有账号和连接同一宿主的各端共用。

开启「一言」后，点击「一言」文字旁的筛选图标即可在浮层编辑屏蔽词，也可通过设置搜索直接打开。屏蔽词每行一个，修改后自动保存；按正文与出处作不区分大小写的字面包含匹配，空行忽略、重复词合并。最多保存 1000 个词，每词不超过 200 字；全部句子被屏蔽时不显示一言，不影响标签、问候语及助手报告的候选句。无效输入或保存失败时保留草稿，关闭设置并确认放弃修改后清除草稿。

窗口行为控制关闭按钮是退出、最小化到托盘还是询问，默认最小化到托盘，在「常规 → 启动与退出 → 关闭窗口」设置。开机启动独立管理系统登录项，不依赖后台服务，仅安装版桌面端支持。

桌面主窗口可拖动边缘收窄为竖屏，最小尺寸为 360 × 520。宽度不超过 760 时，直接使用 WeQ Remote 共用的单栏界面：会话列表与正文单栏切换，底部为「消息、联系人、空间、更多」四个入口，其他功能从「更多」进入；正文左上角返回会话列表。桌面保留原生窗口操作与顶部拖动区，拉宽后恢复并排布局。默认打开尺寸仍为横版。

macOS 单栏使用原生红绿灯时，窗口按钮与页面头部共用一行，不再额外占用一条窗口栏；顶部操作区复用 iPadOS 的占位避让，空间不足时下移，进入全屏后取消额外留位，媒体预览同步适配。头部空白处仍可拖动窗口，按钮与搜索框正常点击；拉宽、收窄保留草稿和输入焦点。开启仿 Windows 窗口按钮时，继续保留独立窗口栏；Windows 与 Linux 的窗口栏不受此项影响。

「自启时显示窗口」位于开机自动启动下方，默认关闭：系统登录自启后保持托盘运行，手动打开或从托盘/Dock 唤出时仍显示窗口。开启后，下次系统登录自启时显示主窗口。关闭自启不会清除这个偏好；托盘不可用时仍显示窗口，避免无法找到应用。

macOS 菜单栏显示彩色 WeQ 托盘图标，左键点击直接打开主窗口。右键点击托盘图标，可选择「显示主窗口」「新建窗口」「重启 WeQ」或「退出 WeQ」。「新建窗口」打开独立的账号选择页。macOS 左上角的 WeQ 应用菜单也有「重启 WeQ」。重启会正常退出应用，再启动并打开主窗口。

macOS / Linux 桌面端可在「常规 → 外观与布局 → 窗口外观」开启「使用仿 Windows 窗口按钮」，默认关闭。关闭时使用系统原生窗口按钮；开启后改用右上角的最小化、最大化／还原与关闭按钮。macOS 主窗口立即生效，Linux 主窗口重新进入账号后生效，独立窗口下次打开时生效。账号选择页始终保持各平台统一样式，右上角提供关闭按钮，不受此设置影响。标题栏空白处可拖动窗口，在线能力受限入口不受拖动区影响。

macOS 的 `Cmd+Q`、应用菜单「退出 WeQ」、Dock 图标右键「退出」及托盘退出均请求彻底退出，不受关闭按钮偏好影响，也不再弹确认框：选中的就是退出，直接结束进程并停止全部后台服务。
关闭按钮偏好为「每次询问」时，若仍有后台服务在运行（MCP、OneBot、QQ 公众号推送、Web、Remote 或 SSE 推送），关闭确认框会列出这些服务，可取消或改为最小化到托盘。
已保存的账号、配对和开机启动设置保留；开启自启时，由系统在下次登录时直接启动 WeQ。
只关闭窗口并选择最小化到托盘时，后台仍正常运行。

推送服务仍启用时关闭登录自启，会提示下次登录后需要手动启动 WeQ，可选择保留或仍关闭自启；

「基础功能 → 互动与防撤回 → 隐藏正在输入状态」采用「默认展示、按需隐藏」：启用范围可选「关闭」「按会话勾选」「永久全选」，关闭时照常向对方展示正在输入状态。选择「按会话勾选」后显示「隐藏正在输入状态的会话」及已选择数量，点击「编辑会话」打开与防撤回一致的独立选择弹窗，只列出私聊会话，点击「保存选择」后按账号与数据源分别保存；关闭未保存的选择时会确认是否放弃修改。「永久全选」则所有私聊都不再展示。私聊输入框不再有单会话开关按钮，添加或移除隐藏会话都在设置里完成。

「常规 → 通知与提醒」将事件通知列为「事件类型／应用内横幅通知／系统通知」三列表格，分普通消息、重点消息、其他通知、应用与任务四个默认折叠的大项，共 23 项。每个大项按列独立汇总，部分开启时开关左半边显示主题色、右半边保留未开启底色，圆钮居中且不显示减号；点击关闭或部分开启时整列全开，点击开启时整列全关；展开不改变开关。数据库异常提醒在「应用与任务」中，默认仅开启横幅，系统通知可单独开启；不再自动弹窗，点击通知后可查看检查详情和修复入口。已有关闭选择会保留，关闭通知不影响健康检查、日志和报告生成。Web 的浏览器通知授权也在本页。

数据库体检的正常进度、正常完成和主动停止不发送横幅或系统通知，进度与结论保留在体检页面和任务列表。发现坏页、结构损坏、实际检查未完成或调用失败时，按数据库异常的通知方式提醒，点击直接返回对应结果；执行状态与诊断分别表达，检出异常不等于检查执行失败。没有页 HMAC、无法逐页校验本身不算检查失败。

新邮件、私聊和群聊等分别保存横幅与系统通知渠道。普通私聊、普通群聊、助手或克隆体的新回复默认仅系统通知；@自己、@全体、群友回复及后台任务失败默认双渠道；后台任务完成和撤回提醒默认仅横幅；红包默认关闭两种渠道。浏览器系统通知需要当前浏览器授权。

通知不展开也能看到关键摘要。群聊显示发送者和消息，重点消息标出提醒原因；引用或回复优先显示新内容，群提醒词显示匹配片段。邮件主题和发件人只出现在未锁定、未开启隐私模式的应用内横幅，系统只提示收到新邮件。任务横幅直接区分完成、部分完成、未完成和等待处理，诊断信息可展开查看。

特别关心、@自己、@全体、群友回复、红包和群关键词行旁的「选择提醒会话」提供四档，应用内横幅和系统通知共用同一范围。「群友回复」只提醒群成员对自己消息的引用回复，私聊引用按普通私聊消息提醒。「群关键词」在所选群聊中按各群设置的关键词规则提醒，这里的范围仅控制通知，消息上的群提醒词标记继续记录。

- **全部适用会话**：也提醒免打扰和收进群助手的会话。这是特别关心以外的默认范围。
- **非群助手会话**：跳过收进群助手的群聊，其他免打扰会话仍可提醒。
- **非免打扰会话**：跳过免打扰会话和收进群助手的群聊。这是特别关心的默认范围。
- **指定会话**：仅提醒选中的会话，可选免打扰或群助手会话，空名单不提醒。

普通消息仍遵循会话免打扰。撤回提醒使用独立的会话名单，默认为空，也可在「互动与防撤回」页编辑。

「未读角标」依次分为「系统应用图标」「主导航」「会话列表常规视图」「联系人页」「菜单」。「主导航」提供消息导航与邮箱导航未读角标；「会话列表常规视图」依次提供群助手、公众号、服务号、频道私聊、已隐藏会话、已删除会话、克隆会话、WeQ 助手会话；「联系人页」依次提供「好友与群通知未读角标」和「好友与群聊未读消息数」，分别控制通知入口和会话列表；「菜单」提供进行中任务、已完成任务、增强包更新和官方公告。WeQ 新版本不产生角标。关闭某类聚合入口的角标后，该入口不再计入消息导航或应用图标角标，未读定位顺序见[消息与联系人](homepage.md#消息与联系人)。角标开关不清空未读、停止任务或改变通知方式。普通会话、助手／克隆回复以及邮件与文件夹的基础未读状态始终正常显示，不再提供隐藏开关。

会话列表、QQ 邮箱及版本设置直接提供对应开关，与集中页共用值，无需跳转。在「基础功能 → 会话列表 → 常规视图未读角标」可调整「会话互动红点」（默认关闭）及八类会话的汇总角标，名称与顺序和集中页一致。「重要消息标记」只在会话列表设置中出现，用一个开关统一控制 @我、@全体成员、回复我、特别关心、群提醒词、新文件、红包和群公告的列表提示，不影响普通未读及通知方式。联系人页等没有独立设置区域的功能仍在集中页调整，不在业务列表旁增加控件。

公众号、已隐藏会话和已删除会话的汇总未读角标默认关闭；已保存的开关值保持不变。关闭不影响入口及进入后的基础未读。

「应用内横幅提醒」分别设置成功、失败与消息通知的停留时长。成功默认 3 秒，失败与消息通知默认 -1（不自动关闭）。消息通知时长适用于「普通消息」「重点消息」和「其他通知」里已开启的横幅，不会打开原先关闭的提醒渠道。后台任务按完成或失败使用对应时长，仍在运行的任务进度不受影响。可填 -1 或 1 至 86400 的整数秒，保存后立即生效并在重启后保留；悬停或聚焦横幅时暂停倒计时。

私聊、群聊和群提醒词横幅会在 WeQ 同步到对应消息的已读位置后收起，无论是在 WeQ、桌面 QQ 还是其他 QQ 客户端读的。多条消息合并为一条横幅时，要读完该批消息才会收起；邮件横幅按单封邮件确认。已读后收起不受横幅停留时间或悬停影响，不撤回已发出的系统通知。

助手、克隆体和克隆群回复随同一会话的阅读进度收起；好友和群通知在整批已查看或相应申请已处理后收起。私聊和群聊的撤回提醒随对应互动确认收起，不依赖会话互动红点，也不会因原消息早已读过而消失。查看当前任务结果后收起该结果的横幅，尚待处理的任务不受影响。

开始安装 WeQ 或确认没有可用版本时收起旧版本提醒；增强包更新横幅只保留仍需更新的项目。Remote 连接请求不再等待处理时收起对应横幅。手动切换省流量模式后不会继续显示与当前状态相反的自动提示。

短期横幅的计时分类与其图标、颜色独立：任务已创建、设置已保存、状态未改变、重复操作提醒、输入校验、文件类型限制、正常空结果（如未找到消息、图片未识别到文字），以及已自动改用文件附件发送等提示使用成功时长；消息加载或逐条转发被主动停止且没有实际失败时，也使用成功时长。读取失败、结果未确认、确认超时等提示仍使用失败时长，不改变原文案和样式。原有常驻提示与长期任务继续使用各自的计时规则，不再有普通短期提示固定回退到 10 秒。

右下角与当前状态关联的横幅会随问题解决自动收起：「待提权」、受限原因及状态检查失败会更新为当前状态，确认恢复后旧警告自动消失，即使失败通知设为不自动关闭或正在悬停也一样。同一目标的连接测试重试会原地更新横幅，通过后不保留上一次失败提示；其他目标的错误、仍未解决或尚未确认结果的提示不因此关闭。

带来源动作的横幅与系统通知可以点击返回具体消息、邮件、任务或设置；普通消息合并后定位本批第一条消息，重点消息合并后定位本批第一条符合所显示提醒原因的消息。连接测试返回被测配置条目，任务记录已清理时不会误选其他任务。横幅中的箭头也可用键盘操作；展开、复制、关闭、拖选文字和播放样例语音各自独立，不触发来源跳转。通知保留发起操作时的对象，切换账号或数据源后不会把旧目标当作当前来源的数据；点击只定位，不自动重试、重发、领取红包或安装更新。「已复制」等普通提示没有需要继续处理的对象时不提供跳转。

需要点击保存才提交的设置，即使值与当前记录相同也可保存，保存完成后仍可再次主动提交；不会因为按钮可用就自动提交。读取尚未完成、正在提交或输入无效时仍可能禁用。

普通数值与文本偏好不再需要保存按钮：通知时长、一言屏蔽词、图片预览内存预算、QQ 秀缓存有效期、空间翻页限速与刷新冷却期、意图感知／推荐回复／互动画像参数、推荐回复回退列表、SSE 调优和更新检查频率，在停止输入 600 毫秒后自动保存，失焦或数字输入框内回车立即提交。中文输入法组合期间不提交，多行文本的回车仍换行；空值、半截数字或无效列表仅保留草稿。保存期间可继续输入，同一配置按顺序提交最新值；请求发出 300 毫秒后仍未结束时在主窗口显示「正在保存设置」横幅，多项慢保存共用一条，结束后收起。快速保存不提示，失败保留输入并提供重试。切页或关闭设置前先提交有效的待保存内容；失败或无效输入仍按原草稿规则提醒。服务端口、连接配置、QQ 个人资料与会话批量选择继续使用各自的明确提交入口。

有可恢复偏好的二级页面在右上角提供「恢复本页默认」，点击后先确认范围与变更；包含该页折叠或条件隐藏的已登记参数，账号偏好仅恢复当前账号和数据源，不再提供重复的卡片级按钮。服务启用开关也恢复默认，弹窗列出将停用的服务；地址、端口、令牌、配对、提供方、账号资料、验证器绑定、下载资源及业务数据保留。自定义目录逐项选择「保留当前／恢复默认」，默认保留，仅更改路径设置，不移动或删除文件。已是默认时仍可查看范围，但没有变更不能确认。恢复前等待已经发出的偏好保存完成，最长等待 15 秒；失败或超时不会执行恢复。恢复后回读受影响设置和共享偏好，不关闭账号或刷新应用；部分失败逐项显示，可只重试失败项。无可恢复配置的信息、工具与反馈页面不显示恢复按钮。设置界面、搜索、MCP 和文档的目录与恢复归属来自同一注册表。

「关于 WeQ → WeQ 存储管理」只提供数据与缓存清理，不再提供默认保存方式、默认保存目录或缓存目录设置；已有偏好、原目录与任务产物保留。保存行为详见[统一导出](export.md)。账号配置管理位于「关于 WeQ → WeQ 账号管理」。

## 主题与聊天显示

聊天设置按「会话列表」「消息阅读」「互动与防撤回」划分，不增加三级导航。搜索设置或使用旧快捷入口时，直接进入对应二级页并定位具体条目；旧「阅读与未读」整页入口进入「会话列表」，其中阅读定位条目直接转到「消息阅读」。旧「消息区域」等名称仍可搜索。

| 二级页面 | 设置内容 |
| --- | --- |
| 会话列表 | 会话预览、重要消息标记、列表行为、八类常规视图汇总角标，以及全部会话视图的隐藏／删除范围；消息导航角标只在通知与提醒中配置 |
| 消息阅读 | 阅读定位、未读分界线、触屏左滑引用、消息补全与内容显示 |
| 互动与防撤回 | 使用 QQ 个性字体发送、隐藏正在输入状态及范围、防撤回方式、保护范围与名单、生效状态、撤回记录，以及前往撤回提醒的链接 |

「消息阅读 → 阅读与定位」提供缺失消息自动拉取设置，所有账号及连接同一宿主的各端共用：

- **查看时自动拉取缺失的消息**：默认关闭。开启后，缺口进入聊天视口时自动串行拉取并混排到时间线，离屏缺口不触发；已隐藏的删除记录不因浏览自动恢复。
- **定位到缺失消息时自动拉取上下文**：仅在上一项关闭时显示，默认关闭。开启后，从引用或搜索等入口定位到本地缺失的消息时，自动拉取目标及附近消息；失败仍保留附近的本地记录和手动拉取入口。
- **自动拉取上下文条数**：仅在上下文自动拉取开启且第一项关闭时显示，默认 30，可设为 1–500 的整数。条数不包含目标本身，按前后消息序号平均分配，奇数时向前多取一条；空槽位、过期记录或可读取历史不足时，实际返回条数可能更少。隐藏选项不清除已保存的取值。

- 主题支持浅色、深色和跟随系统，可自定义主题色及背景。
- 「常规 → 外观与布局 → 组件风格」并排提供 QQ NT、简约、立体，预览包含会话选中态、聊天气泡和按钮。新版简约沿用经典的实心主按钮和选中底色，聊天工具栏更通透，设置分组只保留细分隔线；旧经典与旧简约均沿用这个选项。立体（原「复古」）使用方形控件、立体描边、凹陷输入框与实心选中项。预览选中后立即应用；深浅模式、主题色、背景、密度与风格均为各端共用的同一份设置，不提供单端覆盖。缺失或无法识别的风格选择回落到 QQ NT，默认背景为「纯净」。
- 立体风格同时覆盖侧栏导航、聊天文本气泡、分段选项、设置与收藏／装扮等功能页的工具栏、任务面板及菜单浮层；深浅色分别适配，继续跟随自定义主题色、背景和界面密度，纯图片与表情等消息内容保持原有显示方式。
- 「界面密度」可独立选择舒适或紧凑，两张预览随当前组件风格变化，分别展示三条与四条会话。密度会调整通用控件、设置行、会话与联系人列表、表格的间距，不改变字号、主题色和背景。窄屏保留适合触控的按钮尺寸。
- 在「常规 → 外观与布局 → 字体」可并排预览并选择「特殊数字字体」或「跟随界面字体」。默认使用特殊数字字体，切换立即应用于时间、编号与统计读数，两种方式都保留数字对齐。
- 公共按钮、发送键和列表选中项会选择与底色相配的文字，极浅／极深主色也保留可辨认边界，不改写选定的颜色。清除自定义色后，界面与助手封面恢复当前主题的预设色。
- 消息气泡与消息字体可分别开关，自己和对方的消息均遵循。头像挂件独立控制，包括消息记录中的挂件、本地使用的挂件与自己 QQ 账号的静态挂件；没有额外的消息挂件。
- 同条消息同时带有个性气泡和字体、且两项显示均开启时，等气泡底图解码与字体加载成功后一起显示；加载中或任一项失败时保持默认字体、文字颜色和气泡。仅有一种装扮或主动关闭另一项时，已开启的装扮独立加载，挂件与动画不阻塞文字显示。
- 「消息阅读 → 内容显示」集中 QQ 秀头像、个性装扮、群消息发送者、消息元数据、合并连续发言、语音转文字、文本 Markdown、链接预览及图片预览内存预算。个性装扮、群消息发送者和消息元数据各为一行多选项，每项独立保存。QQ 秀缓存有效期移至「凭据与数据 → 资源加载 → QQ 秀缓存」。
- 「合并连续发言」默认关闭。开启后，私聊、群聊和合并转发记录会将同一人的连续发言分组，头像和发送者信息只显示在组首。
- 纯文本默认显示原文，可按消息切换到 Markdown，也可开启自动渲染；QQ 原生 Markdown 消息的显示不受该开关影响。
- 「消息元数据」的「消息序号（seq）」「日期」「时间」默认关闭，可独立开启；日期按北京时间以 `yyyy-mm-dd` 显示。
- 「内容显示 → 图片预览内存预算」默认 128 MiB，可设为 0–1024 MiB，修改后自动保存并生效。预算内保留最近看过的图片、动画表情和商城表情，超额时优先淘汰较早查看的离屏预览；0 表示不保留离屏预览。预算按解码后像素估算，不是图片文件大小，也不是进程内存硬上限：当前可见图片和动画额外帧可能使实际内存更高。该缓存按渲染窗口独立管理，切换账号时清空，不改变本机磁盘缓存。
- 同一卡片中的「完整消息预热内存预算」用于桌面长聊天。默认 128 MiB，可设为 0–1024 MiB，修改后自动保存。空闲时按滚动方向分批准备完整消息，快滚时优先显示完整行，暂时赶不上时用简化正文兜底。0 关闭额外完整消息预热。额度按消息行和媒体像素估算，浏览器另行管理已绘图块的内存。
- 「消息阅读」可设置「定位到上次阅读的位置」（默认关）和「发送消息后定位到最新消息」（默认开）。「常规视图未读角标 → 群助手」默认关，可在集中页或会话列表设置调整，不影响内部各群的未读数及未读定位。
- 离开会话时，最新消息的下沿已进入可视区域，即视为停在最新，底部留白无需继续滚动。从历史读到这里会清除上次阅读位置。有记录时，「定位到上次阅读的位置」开启会自动续读，关闭会先显示最新消息，并可通过默认开启的「显示跳转到上次阅读位置按钮」手动续读。
- 打开「定位到上次阅读的位置」后，其下的「保留尚未读到的消息的未读计数」默认开启。普通私聊和群聊在前台向下阅读时，消息从屏幕上沿滑出才确认已读；到达会话底部时也确认当前可见的消息。未读数按连续读到的位置更新，跳转保留中间跳过的未读。可用会话菜单的「标为已读」一次确认当前未读。
- 「阅读与定位」中的「显示未读分界线」和「触屏左滑引用」默认开启。前者只控制时间线上的「以下为未读消息」。后者关闭后，仍可从消息菜单引用。
- 「会话列表」最前的「会话预览」卡片提供「显示会话预览」和「重要消息标记」两个独立开关。会话预览默认开启，关闭只隐藏消息和草稿摘要，不影响角标或标记。
- 会话列表不再提供「未读标记」卡片、已读位置上报开关和清除 WeQ 已读记录入口。移除设置入口不改变已有上报偏好与阅读行为。
- 「自动跟随最新消息」默认开启，控制加载完成后新到消息的跟随。会话打开在最新消息时，分批加载也保持贴底；主动向上滚动后保留当前视口。
- 「会话列表 → 列表行为 → 鼠标停留时保持会话位置」默认关闭，各端共享。开启后，鼠标在会话列表内或右键菜单打开期间暂缓自动重排，摘要和未读数继续更新，新会话暂时追加在末尾；移出并关闭菜单后恢复最新排序。触屏操作不触发悬停保持。右键菜单默认显示操作对象并持续高亮目标行，多选时显示会话数量。
- 「会话列表 → 列表行为 → 切换视图时关闭不在新视图中的会话」默认关闭，各端共享。开启后，主动切换视图时可关闭不在目标视图内的聊天面板，不清除草稿，也不自动打开其他聊天。
- 「向下滚动时显示定位到底部按钮」默认开启，向下浏览时可快速回到最新消息，并保留最新消息预览入口；关闭仅隐藏滚动触发的按钮，不影响「xx 条新消息」提醒。
- 发送字体和输入框字体预览在[输入框工具栏的「个性字体」菜单](chat-view.md)配置，跨会话共享。
- 「优先使用 QQ 秀替换头像」默认开启：开启后消息头像换成成员的 QQ 秀全身像（比头像略宽，不挤动消息布局），同时不再显示头像挂件；关闭后恢复头像与挂件。头像进入可视区域后才查询，未命中缓存的成员逐个请求。形象 URL 按账号缓存，有效期默认 5 分钟，可在「资源加载 → QQ 秀缓存」按分钟调整；个性主页共用这份缓存。到期时只刷新仍可见的头像，离屏后等再次看到才刷新；失败时保留旧形象，30 秒后可重试。旧版默认 14 天自动迁移为 5 分钟，其他自定义天数换算为分钟保留。
- 自己发出的气泡在回读前采用 QQ 账号配置，回读后以实际消息为准；「个性装扮」中使用的气泡与字体仍可按作用范围覆盖本地显示，不改变实际发送。
- 链接预览卡片默认开启，只显示 QQ 随消息保存的元数据和本地已有的预览。卡片开启时可设置「自动联网补全链接预览」，允许获取未缓存的网页元数据和封面；开启省流量且不允许加载链接预览时，两类请求都只读缓存。「无封面时网页截图」仅在卡片与联网补全均开启时显示，默认关闭。关闭上级开关会隐藏子项并保留其设置；搜索隐藏项会定位到可见的上级开关。关闭卡片不影响点击链接。
- 应用锁默认关闭。启用开关、解锁方式、验证器绑定和空闲自动锁定集中在同一张「应用锁」卡片内；验证器绑定仍在独立弹窗中完成。
- 隐私模式只遮罩身份、私人内容和凭据：头像、昵称、账号标识、消息与邮件正文、照片、文件名、识别结果等；群人数、时间、消息 seq、等级、个性装扮、统计、操作按钮和任务状态保持清晰。混排区域只遮罩具体字段，不模糊整张卡片或整个气泡；关系图保留匿名节点、连线和统计。
- 隐私模式是视觉遮罩，不改变原始数据、复制结果或普通导出内容，不静音语音／视频。敏感字段的原生悬浮提示会临时隐藏，关闭后恢复。第三方网页、系统文件选择器，以及未建模的数据库／协议／日志原始内容不属于自动脱敏承诺；公开分享前仍需检查截图。
- 桌面端可开启「在菜单中截图瞬间临时启用隐私模式」，默认关闭。开启后截图前关闭菜单并临时遮罩，完成、取消或失败后仅撤销本次临时遮罩，不修改永久隐私偏好；截图期间修改永久偏好，以最新值为准。关闭该选项时保留原来的直点/长悬停截图行为。该选项与永久隐私模式均保存为共享设置；Web 不显示原生截图控件。

## 账号、安全与凭据

账号管理列出已保存配置，可设置默认进入或删除非当前配置；删除不会移除 QQ 本体数据。同号在线/静态配置仍是独立数据来源。

「常规 → 在线能力与授权」紧跟「启动与退出」，集中「QQ 在线能力」与「长期授权」。「QQ 在线能力」卡片内的能力对照默认折叠，新增在线能力使用粗体突出；自动启用和提醒入口紧跟对照表，其后展示启用方式。macOS 的两条路线在宽屏左右并列、窄屏上下排列，副本设置与在线能力受限共用独立浮窗。数据库监听及宿主全局的读取并发位于「凭据与数据 → QQ 数据库管理 → 监听与读取」，防撤回位于「基础功能 → 互动与防撤回」。外部安卓图片缓存位于「凭据与数据 → 资源加载」，仍为全局配置。数据库密钥、rKey、ClientKey 和外部 rKey 集中在「凭据与数据 → 凭据管理」，默认隐藏，离开后重新掩码，不应截屏或写入反馈。在线会话与其他设备密钥扫描也从凭据页打开。

### QQ 在线能力与启用方式

启用 QQ 在线能力后，可在本地记录查看与导出之外，使用当前 QQ 会话提供的在线服务：

| 能力 | 在线能力受限 | 启用 QQ 在线能力后 |
| --- | --- | --- |
| 本地记录与实时监听 | 数据库可读取时，可浏览、搜索、统计、导出，并监听新消息、撤回与表情回应 | 保留全部本地能力 |
| 漫游消息 | 无法主动拉取 | 可补充本地缺失的历史记录 |
| 发送与互动 | 无法执行在线操作 | 可发送消息、执行群操作与管理，并按设置上报已读 |
| 在线内容 | 依赖 QQ 会话的内容暂不可用 | 可使用空间、群相册、收藏、邮箱、装扮等在线内容 |
| 缺失媒体 | 仍可使用已有缓存、有效媒体链接及外部 rKey 等下载链路 | 增加当前 QQ 会话的取票、链接更新与媒体补全 |

macOS 的两条读取路线用于获得相同的在线能力，不需要依次完成：

- **QQ 调试副本，无需关闭 SIP**：准备并启动独立副本，在副本中登录当前账号；与原版共用账号和聊天数据。点击「副本设置」打开与在线能力受限菜单共用的独立浮窗，检查读取端、副本及进程状态，管理启动、更新和权限。
- **原版 QQ，需关闭 SIP**：在 SIP 已关闭的环境保留原安装，在原版 QQ 登录当前账号，WeQ 尝试读取会话凭据，必要时请求管理员授权。

「启用方式（macOS）」中的两条路线使用并列小面板展示，按实际 SIP 检测结果高亮对应路线，并在条件后标注「（适用于本机）」；不再单独展示当前系统状态行。状态未确认或检测失败时不高亮，失败时可重试。其他平台直接说明本机 QQ 的读取和授权流程，不显示 macOS 路线。长期授权是读取路线之外的共用工具，也用于网卡抓包；不能替代 SIP 或调试签名条件。

QQ 已启动、副本已就绪或权限助手已连接，都不等于当前账号 QQ 在线能力已启用；仍需该账号登录、凭据与在线会话就绪。关闭自动策略仍可为当前来源手动启用；长期授权继续作为共用工具独立保留。

静态备份打开时自动识别所选账号目录中的数据库和资源，支持 Windows 的 `账号/nt_qq/nt_db`、macOS / Linux 的 `账号/nt_db`，以及平铺数据库目录自带的 `nt_data`。直接选择 `nt_db` 时也会识别标准布局中的同级 `nt_data`。纯数据库备份不再借用本机另一处同账号 QQ 目录，不提供「关联资源目录」开关；本地缺失的媒体继续走既有在线补全流程。安卓 `chatpic` 缓存导入仍独立保留。

「在线能力与授权 → 已读同步」可开关「向 QQ 服务器上报已读位置」。默认开启；旧版自动阅读与手动标记上报的不同选择在用户修改前保留。开关同时控制两类上报，不影响 WeQ 本地已读。受限或离线时不发送上报；标为未读也不能恢复其他端已清除的提醒。

「自动启用 QQ 在线能力」只控制自动尝试策略。关闭后仍可从「在线能力受限」详情为当前来源手动启用，手动请求仅保存在宿主本次运行中，不写配置或备份，也不代表授权或凭据已经就绪。重载窗口或 Web 页面不会清除请求，切换来源、退出账号或重启宿主后则不继承。凭据、媒体补全、收藏、邮箱和其他在线入口依据当前有效运行态与真实 QQ 能力共同判断，关闭自动策略不会撤销已经明确作出的本来源手动请求。

「QQ 在线能力」标题旁的标签显示当前账号的真实启用状态，不以自动启用偏好或 QQ 进程是否运行代替能力就绪；检测中、等待提权和正在启用分别显示。点击标签可打开状态详情。

「在线能力受限时在窗口右上角显示」默认开启，独立控制右上角的受限状态入口。关闭后仍可点击设置中的状态标签查看详情，不影响能力检查、授权、启用进度或通知。该偏好随通用设置备份与恢复，也可在本卡片恢复默认。

「在线能力受限时通知」仅用于正常运行后在线能力再次受限的被动提醒，可配置应用内横幅和系统通知。启动自动尝试 QQ 在线能力时，无论成功、失败或等待授权均不发状态通知；手动启用的授权、进度及结果不受此项影响。关闭期间会继续跟踪状态变化，重新开启不会补发已经发生的提醒。

旧配置备份没有包含的设置字段会保留本机已有值，仅为本机也缺少的字段补默认值；明确选择「恢复默认设置」仍会重置通用偏好。已读自动/手动混合组合按原值往返，宿主手动 QQ 在线能力请求及截图临时覆盖不在备份中。

「基础功能 → 通话与录音」集中配置通话连接方式、录音内容与保存位置，以及抓包排障选项。

录音来源可选仅本端、仅对方或双方混合；可同时录电脑正在播放的声音（Windows、Linux 和 macOS 14.2 及以上桌面端支持；macOS 请按系统提示授权或选择采集来源）；保存位置默认按账号放在应用数据目录的 `recordings` 下，也可自选目录。录音**不会自动开始**，要在通话接通后到通话窗口里手动点录音键。通话结束后窗口里可直接播放；如果这通电话在聊天里留下了通话记录，那条消息旁边也会出现播放按钮（QQ 客户端写入这条记录之前不会出现）。通话窗口底部的「通话与录音设置」抽屉改的是同一份配置，改哪边都一样。

「连接方式 → 禁用 P2P 直连」可强制私聊通话媒体走腾讯服务器中继，用于对比排查通话卡顿，改动只对之后发起的通话生效。「抓包与排障 → 记录 UDP 流量」打开后，发起的私聊和群聊通话会把本机收发的 UDP 数据报写成 pcapng，放在录音目录的 `udp/` 里。群通话的文件名包含群号，格式与 UDP 抓包面板的导出一致，可以直接用 Wireshark 打开。

点击窗口标题栏自己的头像打开通用名片，展开完整资料页后可直接点击昵称、性别等可编辑字段，个性签名和头像分别从对应详情中修改。所有显示本人在线状态的位置，包括桌面及移动端顶栏、名片和资料页，均可点击整段状态，在旁边打开同一个小对话框；基础状态、扩展状态、自定义文字和表情共用一份草稿、一个保存按钮，不分别提交。自定义状态表情复用聊天的图片网格，支持搜索和选中预览，仅展示状态接口支持的本机经典表情；Escape 先收起表情网格，再关闭状态窗口。操作需要当前账号在线能力就绪，会真实修改 QQ 账号资料；离线保持可选择的只读文本，不变成复制入口。保存失败保留输入，关闭或切换账号、数据源会收起编辑器并丢弃未保存的草稿；选头像期间切换账号或数据源，会取消旧文件的提交。

窗口标题栏的昵称与个性签名之间显示 QQ 本地缓存的在线状态及已支持的扩展状态图标，每 15 秒刷新；修改状态后也会刷新。状态未读到或未知时不显示，长文案截断后可悬停查看完整内容。本地缓存刷新不代表已向 QQ 服务端实时查询。

### QQ 代理连接

「设置 → 常规 → 在线能力与授权 → QQ 代理连接」显示连接状态、待同步任务和错误。在运行 WeQ 的电脑上打开 QQ，从登录窗口右上角的菜单进入「网络设置」。选用 HTTP 代理，地址用 `127.0.0.1`，端口以 WeQ 卡片上显示的值为准（默认 `19081`）。确认设置后即可登录账号。

卡片中的「自动同步本人消息与已读」默认关闭。开启并连接代理后，WeQ 已成功发送且 QQ 本地缺失的普通私聊／群聊消息会自动补投。已读同步沿用已读上报设置。

开启「通过 QQ 代理加速实时更新」并连接代理后，WeQ 可利用 QQ 推送减少重复读库和刷新，可能显著提升性能。支持的普通文本可以在 QQ 落库前显示。能确认优先级的普通通知也可提前发出，点击后按消息序号定位。已读、撤回、戳一戳、表情回应和群资料变更按会话、消息或群更新。该项默认关闭，沿用「实时消息」总开关。断线或遇到未识别的变化时由数据库监听校准。

开启自动同步、代理实时接收或选择使用代理的防撤回方式后，当前账号尚未连上代理时，主窗口右上角显示「QQ 代理未连接」。收到代理连接请求、还在确认账号时会短暂显示「正在确认 QQ 代理连接」。点开可查看配置步骤，或点「代理设置」回到此卡片。确认运行中的 QQ 实例后，可点「重新启动 QQ」。已配置调试副本时，「打开 QQ」会打开副本，普通 QQ 正在运行时可重启切换到副本。「QQ 代理未连接时在窗口右上角显示」默认开启，可独立关闭。

端口被占用时，可在同一张设置卡片填入其他端口并保存。保存会在运行代理的 WeQ 宿主上启用新端口，并停止旧端口接收新连接。已有连接继续转发，QQ 下次连接前需更新代理端口。新端口监听或保存失败时，原端口配置保持有效。

代理由独立后台进程维持，WeQ 重启后接续已有连接，代理子进程异常退出后自动重启。消息补投按账号及消息身份记录，恢复时先查询 QQ 是否已接纳。关闭自动同步会保留正常转发，停用代理前需先恢复 QQ 的网络设置。Web 和 Remote 操作复用连接宿主的同步服务。

### 长期授权

桌面端在「常规 → 在线能力与授权 → 长期授权」检查、启用、修复或撤销本机权限助手。打开该页或回到 WeQ 窗口时会自动检查，检查失败或需要手动处理时显示「重新检查」。启用和撤销均需管理员批准，不保存管理员密码；打开设置或搜索该项不会自动安装。提权提示与导出授权提示中的「管理长期授权」会结束本次待处理请求并跳转，完成设置后需重新执行原操作。

助手是独立的小型原生服务，不复制 Electron、Node 或聊天数据。系统只安装一份可执行文件，按系统用户分别授权；撤销自己的授权会中断自己的助手操作，最后一位用户撤销时移除共享组件。安装后系统启动服务，空闲时不抓包；WeQ 关闭或连接断开后清理该连接持有的抓包会话。

macOS 使用 launchd，Windows 使用系统服务，Linux 使用 systemd。macOS 的 SIP、Windows 的 Npcap 依赖及其他系统保护仍然有效，长期授权不能绕过它们。Linux 无 systemd、旧版原生包未包含助手或服务不可用时，不会假报已启用，原有临时授权路径保留。

普通应用更新可继续使用协议和接口都兼容的助手；助手自身仍遵循原生组件有效性约束。组件过期、协议不兼容或权限助手接口已更新时，需要更新原生组件并重新「修复授权」，旧授权不会继续生效；系统授权记录不因过期自动删除。需要修复时，「在线能力受限」详情会直接显示原因和「管理长期授权」入口，不再让界面停在「正在启用 QQ 在线能力」等待。长期授权属于本机系统状态，不随配置备份迁移到其他电脑。

安装失败时设置页会给出中文原因和下一步，而不是原生组件的英文原始报错。常见的一种是安装目录不安全：Linux 的 `/opt`（或 macOS 的 `/Library/PrivilegedHelperTools`）必须由 root 拥有且其他用户不可写，从备份恢复数据后目录属主可能变成你自己的账号，此时会提示执行 `sudo chown root:root <目录>`，命令需要用户在终端里自己执行——WeQ 不会代改系统目录，否则该目录又会变成普通用户可写。修好后点「重新检查」再启用即可。

### 在线能力受限

macOS 开启 SIP 时，详情随实际状态提供一个主操作，例如准备并打开副本、登录其他账号、重新启动 QQ 或启用在线能力。「副本设置」直接显示。为当前来源打开 QQ 后，检测到当前账号登录会继续启用在线能力。请求仅在宿主本次运行对当前来源有效，不修改自动启用偏好。创建或更新副本后，相关权限仍可在副本设置中按需处理。

QQ 不在线、当前来源未启用 QQ 在线能力或在线会话尚未就绪时，标题栏右侧显示红色的「在线能力受限」；QQ 在线能力就绪后不显示。启动自动尝试全程保持静默，即使最终受限也不发横幅。当前来源曾确认 QQ 在线能力就绪后，再进入受限状态才按提醒设置显示可点击横幅，打开与标题栏相同的详情，不遮挡整个窗口，仍可浏览本地聊天记录。自动恢复只收起横幅，不另发成功通知；在线能力受限时手动启用会显示授权、进度和结果，全部受限原因解除且确认恢复后显示「已启用 QQ 在线能力」，停留时长遵循成功通知设置。切换来源不会继承旧来源的提醒或恢复回执。

详情打开时会自动刷新登录、读取权限与在线能力状态，关闭后恢复原有检查频率。QQ 不在线时，可点「打开 QQ」，使用 Web 时会打开 WeQ 宿主上的 QQ。请登录当前账号，WeQ 会根据本来源的自动策略或手动启用请求继续检查。安装和启动错误会在详情内显示，不会自动改变自动启用偏好。管理员授权请求在详情内提供密码框。关闭详情仍保留请求，超时后自动清理。密码不保存到配置。授权后，WeQ 会在会话凭据就绪时刷新并恢复在线功能。受影响功能的悬停提示以「在线能力受限，无法……」说明不可用的操作。

若 QQ 刚登录时只读到部分凭据，或设备身份暂未就绪，后台会延迟重试。此时也可点击「重试获取在线凭据」，补齐后自动恢复。已有在线票据仍有效也不会阻止补齐当前会话；身份暂缺本身不会反复请求管理员密码。明确取消授权后则保持安静，直到手动重试或 QQ 进程更换。

提交授权后，等待凭据读取、原生会话登记或自动重试期间，标题栏和常驻进度提示持续显示「正在启用 QQ 在线能力」。不会因密码框关闭、刷新请求结束或旧的完整状态缓存而提前报成功；当前会话真正就绪后才结束进度并显示恢复成功。明确取消或确认失败时回到可重新检查的受限状态。

macOS 已明确拒绝当前 QQ 的调试读取时，详情会引导使用调试副本。普通 QQ 正在运行时，「重新启动 QQ」会先校验调试副本，再退出普通 QQ 并打开副本。退出超时会停止切换。「副本设置」可在凭据等待期间打开。

有尚未处理的管理员授权请求时，标题栏、详情及横幅优先显示「待提权」，不显示进入中的旋转进度或自动重试说明。最后一项授权提交后才切回「正在启用 QQ 在线能力」；恢复期间若再次需要授权，会重新显示待提权。

系统原因按实际能力显示：macOS 桌面端在 SIP 开启且 QQ 不在线时，启动页和账号页均引导创建、启动独立的 [QQ 调试副本](macos-debug-copy.md)，不再提供普通「启动 QQ」按钮；缺少会话凭据时也提供副本管理入口，无需关闭 SIP。读取端也必须带调试权限，管理员密码不能替代签名权限。Linux 遇到 ptrace 权限限制时提供临时提权及免密重试；Windows 不显示 SIP 或 Linux ptrace 引导。凭据完整且功能可用时，不会仅因进程不是 root 或 SIP 开启而显示受限。状态检查失败单独提示，不冒充 QQ 离线或待提权。

应用锁支持 TOTP 及平台提供的系统认证，可设置空闲自动上锁；不能把锁屏当数据库加密。

[防撤回](anti-recall.md)在「基础功能 → 互动与防撤回」直接显示四档保护方式、当前来源的生效状态和保护名单，也可在本页选择撤回通知方式和提醒会话，与「常规 → 通知与提醒」共用设置。两类名单按账号与数据源编辑，未保存关闭需确认。撤回目录和会话消息在同一遮罩工具内切换，可返回目录；设置页面与侧栏始终保留。基础功能中的 QQ 空间提供专用分页限流，保存后即时影响新派发请求，不清零近期用量；QQ 邮箱页面保留查询间隔及通知、红点设置的直达链接，相关通用偏好全局保存，无需先打开账号即可配置。

QQ 空间的「在线翻页限速」使用“每 [秒数] 秒最多 [页数] 页 [保存]”单行表单；普通状态重读不覆盖未保存输入。「不让 ta 看我的空间」「不看 ta 的空间」以头像和昵称排列名单，接口未返回昵称时补读本地资料，未取得资料时明确标记，QQ 号可在悬停时辨认。点击头像或昵称打开对应名片；点击标题旁的加号可搜索好友或输入 QQ 号添加，点击成员旁的叉号并确认后移除。添加、移除后重新读取名单核对，未确认时保留输入。读取失败可重试，不会显示成空名单；好友资料中的对应单人开关仍保留。

## API 配置

每个 LLM 模型旁可点击「自动检测能力」，使用少量合成文本和内置色块图片检测聊天、视觉与向量接口，可能产生 API 费用，不发送聊天记录或个人图片。检测通过会勾选对应能力，服务方明确不支持则取消勾选；鉴权失败、限流、超时、网关错误或无效输出显示「未确定」，保留原选择。视觉检测需正确识别两张不同颜色的图片，接口接受图片本身不算通过；「未确定」不等于不支持，仍可手动调整。结果仅更新草稿，点击「保存服务商」后生效。模型列表导入的能力仍是按名称猜测，不代表实测结果。

「AI 功能 → API 配置」分为 LLM 和 TTS 语音合成两块，服务商继续使用原有编辑弹窗，不替换设置侧栏。LLM 可分别保存多个服务商和模型，默认模型和能力按钮统一按「聊天、视觉、向量」排列。三类默认模型独立选择，只列出支持对应能力的模型，选择后即时保存，也可明确清空；默认向量模型不要求支持聊天。

默认选择按服务商 ID 和模型 ID 保存，修改服务商名称、端点或密钥不改变引用；删除已选服务商或模型时保留选择并显示不可用原因，不自动切换到别的模型。读取失败可重试，保存失败保留原选择。原有各功能的显式选择和未选择状态不因此改变。

意图、互动画像、推荐回复、新建及编辑克隆体、WeQ 助手等 API 模型入口默认选中「默认（当前：具体模型）」，不再提供「未选择」；未指定聊天模型的旧配置也使用默认，已有具体模型保持原样。可选向量检索仍可选择「不使用向量」。每次调用按对应能力解析默认模型：聊天使用默认聊天模型，图片理解使用默认视觉模型，向量检索使用默认向量模型，不互相借用。默认未配置、模型已删除或能力不匹配时明确报错，不改用其他服务商。全局默认模型本身仍可清空，不继承自身；旧配置不自动填入默认向量模型。

意图感知、互动画像和推荐回复的设置按用途直接分区展示，不再设置「高级设置」折叠入口；克隆体回复设置与漫游拉取参数同样直接展示。

意图分析和推荐回复会在实际默认聊天模型变化后更新缓存，旧模型的迟到结果不会写入新缓存。克隆体的向量索引绑定训练时的模型：若训练时选了默认向量模型，之后更换默认导致索引空间变化，需要重新训练，不能将原索引交给另一模型查询。导出独立 bot 时会固定导出当时实际使用的模型和服务商，不依赖电脑之后的全局默认。

API 配置备份包含默认聊天、视觉、向量模型。导入旧备份缺少某类默认模型字段时保留本机对应值；跳过冲突保留本机已存选择（包括未设置），覆盖冲突则采用导入值，允许明确清空。

意图感知、互动画像和推荐回复是三个独立设置页，首先展示「功能与模型」，之后分别展示显示方式、触发方式、分析或统计范围、生成参数、结果展示、请求与缓存等适用分区。功能区放各自的启用开关和「自动／手动」模式，模型配置统一使用「运行方式」「服务商与模型」等名称；推荐回复只使用 API，不显示不适用的运行方式切换。关闭功能后仍可配置模型，不会连带修改其他功能。开关、模式和模型选择即时保存，数字参数按上面的规则自动保存；读取失败可重新读取，保存失败可重试。旧配置默认自动；手动时通过消息右键或多选菜单运行意图感知、进入互动画像页生成画像、点击推荐栏的开始图标生成推荐，具体见[意图感知](intent-sense.md)。

所有参数分区直接展示，按参数名称搜索可定位，不会因定位而保存参数或启动模型。切换页面保留草稿，非活动页面停用无必要的读取与订阅。本地意图资源仅在本地模式下显示于「功能与模型」内，不另设卡片；资源全局共享，功能选择仍按原账号作用域保存。不适用的模型配置直接隐藏，旧搜索入口定位到运行方式；实际错误与重试入口保留。意图感知页的「意图与推荐缓存」同时清除这两项功能的缓存，不影响互动画像。

「显示方式 → 自动分析时显示胶囊动画」默认开启。关闭后，自动分析得到结果时才显示胶囊，等待期间不占空间。已有结果直接显示。单条手动分析始终立即显示等待动画，手动批量分析在开启「常驻显示」时显示等待动画。

推荐回复默认关闭「自己发送后推荐回复」和「回退内容」。开启回退后，模型未配置、调用失败、冷却或没有有效候选时，从列表随机抽取不重复内容，数量不超过推荐候选上限；关闭或列表为空时不回退。设置页通过「回退内容列表」旁的「管理」按钮添加、修改、删除句子，编辑后自动保存。关闭对话框不会丢弃未完成的编辑；恢复默认列表使用「推荐回复」页面右上角的「恢复本页默认」。每条最多 500 字符，最多 100 条；保存时去除首尾空白，不接受空白或重复项。列表编辑不影响已保存的历史。

推荐回复的「缓存与历史」可设置「最近推荐过期时间（分钟）」，默认 1 分钟，`-1` 永不过期、`0` 立即过期。仅在进入会话时限制尚未覆盖最新消息的推荐，已覆盖最新消息及停留期间正在显示的候选不因超时清空。因过期而没有候选时，推荐栏显示距上次推荐的时间，最多两个单位，满一分钟不显示秒；历史推荐仍可展开查看。

「缓存与历史 → 每会话保留的推荐轮数」默认 500，范围 0–10000，一轮包含一次生成的全部候选。改设置不立即删除历史；下次生成并保存新一轮时，按上限保留最近轮次并清理淘汰轮次的详情。0 只停止新增保存，已有历史仍可读取，当前推荐、缓存和本轮详情照常可用；未保存的本轮详情随当前缓存保留，不在重启后恢复。

## 凭据与数据

### 备份与恢复

应用备份或恢复默认设置前，会先等待已有请求结束；等待超过 15 秒时终止本次操作，显示仍未结束的请求，并恢复弹窗操作。此时尚未修改配置或数据，相关任务结束后可重试，不会强行中断原请求或在其仍运行时替换文件。

配置备份、读取与上传备份、预览及应用恢复、恢复默认设置均不向任务列表新增任务；操作进度与错误直接在设置页或确认弹窗中显示，恢复成功后不常驻显示结果卡片。

「关于 WeQ → 配置备份与恢复」位于 WeQ 账号管理之后，支持导出、导入及恢复备份。Native 组件过期或损坏时，也可从组件诊断界面进入，不必先打开 QQ 账号。

- 备份范围可分别选择通用设置、账号配置与偏好、API 配置与凭据、克隆体与助手数据；账号和克隆数据域可单独勾选。「通用设置」下的「界面外观与布局」可独立排除。
- 备份为**未加密 ZIP**，可能包含 API 密钥、数据库密钥、克隆对话、记忆与参考语音，应存放在可信位置。不要作为问题反馈附件公开发送。它不是完整磁盘备份，不包含 QQ 原库、漫游 SQLite 缓存、本地模型、bot 运行入口或本机应用锁密钥。
- 桌面端选择文件保存／读取；Web 端分片上传 ZIP，导出后提供下载入口。单文件最多 64 MiB、总展开数据最多 256 MiB、归档最多 260 MiB、8192 项，超限会明确报错，不生成部分成功备份。同名输出文件不会被覆盖。
- 导入先选择范围和冲突策略，再查看预览并确认恢复。通用设置总会应用；账号、克隆或同 ID 的 API 项可选择跳过或覆盖。覆盖克隆数据域会替换该域，不合并对话。
- 跨机器重新选择 QQ 数据源后，数据域标识可能不同。可将来源映射到**同 QQ 号**的本机已有账号配置；这时保留目标账号的接入信息、密钥与运行凭据。多个来源不能同时映射到同一目标。
- 「账号配置与偏好」会备份草稿中由 WeQ 保存的 PNG、JPEG、GIF、WebP 和 BMP 图片，并将引用定位到目标账号的素材目录。包含图片的包需用支持该功能的版本恢复。普通聊天草稿的 QQ 原记录由 QQ 数据源提供。
- 默认保留本机导出目录和外部图片库路径；如明确取消，可恢复来源设置中的路径引用。不会因缺少外部缓存根而创建替代目录。缺少的克隆素材、模型提供方或 QQ 装扮资源会提示，可能需要重新配置或获取。
- 确认后在当前进程内应用，无需重启桌面端或 Web 服务。请先保存正在编辑的内容；恢复会关闭当前账号，等待旧服务收尾，应用文件事务后通知各窗口与 Web 页面刷新。导出、模型下载或数据库修复在途时，会说明具体任务，请完成或停止后重试。
- 恢复失败会回滚；回滚未完成时保留原件与事务现场，并显示独立恢复错误，可重试，不能在混合数据上继续打开账号。恢复备份成功后直接显示业务页面，不再要求点击「继续」；恢复全局默认设置会清除各页的浏览位置，重新进入设置时从默认页面开始，不再回到恢复页。成功结果及附带提示不常驻显示为卡片；失败或待处理的界面偏好交接仍在本页显示。旧版本遗留或中断后尚未应用的暂存，可在原位置直接「应用恢复」或取消；冷启动仍可接续恢复。
- 共享设置在电脑端统一恢复并通知各端；布局现场的恢复回执由发起设备确认。旧备份中的主题、隐私等界面字段会转为共享设置，成功持久化后才确认回执；确认重试不会覆盖后来修改的共享值。换设备时可明确认领尚未应用的恢复回执，或放弃该回执；后者不会撤销已恢复的 WeQ 数据。

「配置备份与恢复」页提供「恢复全局默认设置」，用于一次恢复通用设置、界面外观与布局及所有账号的功能偏好，同时清除各账号与各层级页面的选中页、筛选、滚动等浏览现场，保留正文草稿和会话整理。WeQ 助手的通用设置也恢复默认，助手会话及其单独设置不删除。确认弹窗默认保留 API 配置与凭据（包括助手的外部 MCP 连接）、WeQ 服务配置和自定义目录，可显式选择清除或重置；重置目录仅更改路径，不迁移或删除已有文件。账号配置、聊天记录和克隆体数据不删除。读取恢复范围失败时可重试，未读取成功不能确认；存在待恢复数据或界面恢复回执时，先处理原恢复任务。

各二级页面的「恢复本页默认」及卡片恢复入口继续保留，不扩大到其他页面或账号。全局恢复与本页恢复共用注册表中的默认值来源、差异规划器和目录选择规则；全局恢复仍通过配置备份事务落盘，确认后关闭当前账号并刷新各端，无需重启 WeQ。

全局恢复也会清除各账号的重点消息提醒名单、取消省流量模式的临时覆盖、将性能记录恢复为轻量档位。已读记录、置顶、会话免打扰和性能历史继续保留；性能历史的保留天数和容量不变。

### 缓存与维护

「关于 WeQ → WeQ 存储管理」只管理 WeQ 自身数据与缓存的占用及清理；直取偏好位于「凭据与数据 → 资源加载」，不改变存储清理，也不是全局离线开关。「空间清理」分别显示本页占用、普通缓存可清理大小和历史数据库备份占用。未勾选时只清理可重新下载或生成的普通缓存；收藏媒体、QQ 秀、共享装扮和装扮预览也支持清理。防撤回配置不再列入；清除意图分析、容错记录、克隆与助手数据、旧装扮资源时保留各自的应用设置和旧配置，配置文件也不计入这些项目的占用。

历史数据库备份置顶并默认展开，显示账号、数据库、备份时间、占用及修复记录关联状态。删除备份只移除该份文件、更新备份清除状态，保留修复记录与报告；修复记录在「数据库修复」中管理，不再提供整个修复工作区的清理。「历史程序修补备份」单独展示，不与数据库备份混淆。元数据不能确认归属的备份仅统计和定位。

识别结果、漫游记录、克隆与助手数据、导出、搜索索引、模型等与普通缓存分开。明确选择并确认损失后，先在当前进程清除可直接处理的项目，不默认重启；当前服务持有的配置、数据库等不会被直接删除。若剩余项目被占用，再单独询问是否「重启并继续清除」，且只重试被占用的剩余项目；取消重启保留这些项目，已完成的清理不撤销。权限、路径校验和读取失败会显示具体原因，不冒称重启即可解决。清除结果保留在存储管理中。

「关于 WeQ → 配置备份与恢复」提供备份导入、导出、恢复备份和恢复全局默认设置；单页偏好也可使用二级页面右上角的「恢复本页默认」。恢复默认不删除整个账号配置目录或全局配置文件，原有配置备份包内容不变，不会将整个桌面运行目录加入备份。桌面磁盘、代码、GPU 与着色器缓存归入「关于 WeQ → WeQ 存储管理」；远程连接身份、Cookie、界面偏好、锁文件等运行状态不提供空间清理入口。闪传下载成品不参与空间清理，旧文件保留原位，可从下载任务定位或打开旧下载目录。

清理项目按用途合并：同类缓存跨目录显示为一行，桌面各类运行缓存合并为「桌面运行缓存」，同时保留来源路径；空项目和空分类不显示。数据库备份仍可按份选择，损失影响不同的数据分别列出。

清除备份会失去回滚能力，清除密钥配置需要重新配置，原图或云端内容已过期的数据可能无法恢复。由托管 QQ 等其他程序占用的项目需先退出对应程序。确认退出后清除时，请先停止正在进行的任务，等待自动重新打开应用，不要在清除期间手动启动。默认缓存清理不会包含风险数据。应用安装资源交给系统卸载，未知业务目录、符号链接与统计不完整的项目不开放删除。Web 页面仍可清理普通缓存，风险数据需回到电脑桌面端操作。

读取失败或统计不完整可以刷新重试。显示的是逻辑文件大小，不代表卷实际分配空间；其它 QQ 数据目录和任意外部导出目录不在这项统计内，「凭据与数据 → QQ 资源管理」的 QQ 资源统计独立保留。托管 QQ 数据目录可能包含自己的本地聊天库和媒体，清除它们可能永久丢失记录，需先退出托管 QQ 并自行备份。

「凭据与数据 → QQ 数据库管理」依次提供「数据库浏览」「监听与读取」「数据库检查与修复」三张卡片。「数据库浏览」打开独立窗口；「监听与读取」集中数据库监听与读取并发设置；「数据库检查与修复」只保留异常通知设置的直达入口和检查修复工具，不再提供容错级别、账号容错记录或隔离表列表，内部不使用分组分割线。旧入口仍定位实际设置，不会自动执行工具。

数据库读取遇到损坏时自动尝试其他访问路径，不主动省略数据。私聊／群聊导出发现未读区间时，任务进入「等待处理」，可以跳过该区间继续、尝试修复或结束任务；也可以仅对本次任务选择自动跳过后续坏区间。分块读取仍失败时，结束整张表的读取需要单独决定，已有结果保留；没有可保留结果或读取本身不能拆分时，不提供跳过选项。跳过后的任务显示「部分完成」，明细保存在对应任务的日志和完整性报告里，不作为账号偏好影响其他任务。尝试修复会先暂停当前任务，修复后重新打开数据源并重试任务，已有消息按身份去重，不沿用重建前的数据库行游标。

「数据库读取并发上限」默认 4，可设 1–8，所有账号和连接同一宿主的各端共用；修改后无需重启，调低不打断在途读取。连接按需创建并在空闲后回收，重查询另有限流，提高并发也会增加 CPU、内存和磁盘负载。此能力需要配套 native，旧组件仍串行读取，更新后使用已保存的上限；写入与建索引不按读取并发数放开。

占用汇总和刷新位于列表上方，「开始清理」位于列表最下方。历史数据库备份固定置顶，其他分类和组内条目按占用从大到小排列；同量备份按时间从新到旧排列，未识别数据置底。展开分类可查看明细并定位文件。零占用且统计正常的项目不展示；`.DS_Store`、`Thumbs.db` 和 `desktop.ini` 不单列，仍计入总占用，不会因此删除这些文件。

原维护工具按用途归位：「QQ 数据库管理」最前面的「数据库浏览」入口打开独立系统窗口，承载表格、SQL 与编辑模式，关闭设置后仍可继续浏览；手机或弹窗不可用时使用全屏工具页。工具栏「导出」打开公共明文导出面板，默认选中当前库，仍可在同一来源中扩选；取消后保留原浏览现场。「QQ 资源管理」（原「QQ 存储管理」）直接在正文提供占用概览、资源清理和资源浏览，共用扫描状态，清理确认及逐项结果也留在原页；密钥扫描位于「凭据管理」；QQ 登录账号工具位于「QQ 高级工具 → 登录记录与设备标识」。设置打开工具不关闭设置侧栏。资源查看按表情 / 头像 / 图片与视频 / 文件 / 语音 / 空间分组浏览 `nt_data` 资源，详见[本地资源页](database-view.md)。静态账号不可用的资源维护会禁用；清理和修复仍需选择与确认，打开分类或搜索结果不会直接执行。抓包、签名器与逆向解析也位于「凭据与数据 → QQ 高级工具」，说明见[维护与诊断工具](wonderful-tools.md)。

扫描遇到读取失败或数量上限时，会保留部分统计并提示重新扫描，不把部分结果当成完整清理范围。清理只删除白名单目录内的普通文件，不跟随目录链接；空目录和链接保留，不影响主动下载文件或关联的外部原件。结果中的删除量是成功删除文件的逻辑大小，不代表磁盘实际可用空间增长；失败项单独计数，完成后统一刷新统计。

资源清理页显示当前类别、已处理类别数和失败文件数。「停止后续清理」让当前类别收尾，再停止余下类别。点「后台进行」可将同一次清理交给任务列表，收尾结果仍可在那里查看。

数据库修复的体检、修复、记录和回滚均在独立窗口内，默认使用系统边框，macOS / Linux 开启「使用仿 Windows 窗口按钮」后下次打开改用自绘标题栏。窗口跟随主界面主题和主题色，收起设置或账号返回主页不会卸载正在使用的修复界面；重复打开会聚焦原窗口，不会将其目标静默换成另一账号。应用锁定时隐藏修复内容，关闭主应用时一并关闭工具窗口。

打开数据库修复不自动检查。「开始扫描」和「深度体检」由用户主动启动；深度体检包含常规扫描。按账号及本次数据源锁定全部目标数据库后扫描，等待决定时继续持锁，修复直接消费已有结果。个别库未完成不妨碍修复其他就绪库；停止扫描保留已完成结果与锁，可继续扫描或主动结束维护。默认勾选支持修复的异常库，其他已扫描、可修复的库也能手选。

「停止修复」中断尚未提交的重建并跳过后续数据库，已经成功的库不回退；批次结束后自动统一解锁。等待决定时关窗会询问是否放弃维护，修复开始后关窗只关闭界面；修复中退出应用会询问是否停止。历史报告长期本地保留，可查看和导出 HTML、Markdown、JSON，查看不会重新检查或覆盖旧结果。完整用法见[数据库修复](wonderful-tools.md#_3-数据库修复)。

## 增强功能

- 「WeQ 助手」将聊天模型、思考强度、图片处理、运行模式和运行中发送收在「模型设置」，并独立保留「提示与工具」。会话顶部的「助手设置」默认进入同一组模型设置；各会话输入区仍可独立覆盖聊天模型和思考强度。详见[WeQ 助手](assistant.md)。
- 「增强包」分为自动更新设置与资源管理两张卡片，四个包按行显示名称、描述、占用及操作。默认自动检查、手动安装，检查频率跟随「版本与更新」。自动安装只更新已安装包，并直接进入任务列表。手动安装、补齐和更新可在资源行查看进度、暂停、继续、重试或转到后台。检查状态和失败原因保留在资源行，多个可用更新合并为一条提醒。检查与下载均遵循省流量设置。最新版需要更高 WeQ 版本时，行内提供「前往 WeQ 更新」链接。恢复本页默认只重置开关。详见[增强功能](model-resources.md)。
- 「识别与转写」合并原图片识别和语音识别页，只保留两类 QQ 在线并发与文字筛图偏好。模型管理统一在增强包页；自动语音转文字仍在「基础功能 → 消息阅读」。

- 「API 配置」维护提供方、Base URL、API Key、模型能力与 TTS 语音合成服务，可从服务方拉取模型列表。不要在反馈中提供密钥。
- 「默认视觉模型」独立于默认聊天模型，供所有 AI 功能共用，初始未选择。各功能的「图片处理偏好」可选文字占位、OCR 或视觉模型；助手与克隆聊天只提供后两项，默认视觉模型，其余功能默认文字占位。偏好在本宿主的各账号与各端共用，不提供账号或设备覆盖。
- API 与 TTS 都可新建多套配置，包括同名、同厂商或同地址但密钥不同的配置。新建分配独立标识，编辑及重复保存沿用原标识，不覆盖其他提供方或改变已有克隆体的引用。模型选择按提供方分组，同名配置另附标识以区分，未选择的提供方不会自动接管调用。
- API 与 TTS 的连接测试在横幅中显示进度和结果，不锁住配置弹窗，也不自动保存配置。请求使用启动时的地址、凭据和模型；测试期间可修改、保存或关闭表单，未保存修改仍按原规则确认。同一配置的在途测试防重复，不同配置可独立测试；关闭设置后仍会完成原任务，失败不另弹对话框。TTS 成功生成的样例语音可从结果横幅重播。
- 对带温度参数的模型调用，若服务明确拒绝该参数或仅允许模型默认温度，会去掉 `temperature` 后重试一次，保留原配置值、模型和上下文。参数范围／类型、鉴权、限流和网络错误不会触发这种回退；两次实际请求在 API 用量中分别记账。助手已有正文、推理或工具片段后不重新生成。
- 「[意图感知](intent-sense.md)」全局配置总开关、API / 本地引擎、分析上文与缓存参数，保留本地模型选择与前往增强包的入口；分析结果仍按账号保存，单会话开关在会话头部的会话设置里。
- 意图模型资源仅在本地模式直接展示；「常驻显示」「悬停显示」及「自动分析时显示胶囊动画」位于意图感知的显示方式分区，旧高级设置搜索入口仍可定位。
- 「推荐回复」独立配置启用开关、API 模型、自己发送后推荐及推荐上文条数，不受意图感知开关或分析引擎可用性约束，也不使用本地模型生成或自动发送消息。
- 「识别与转写」中的「识别并发」与「转录并发」范围为 1–32，默认 5；开始导出时读取保存的值。导出对话框只保留本次识别、转写和在线功能开关。
- 「OCR 前先筛图」默认开启，全局控制导出、助手及 MCP 等非手动 OCR：先筛除无文字图片，再执行识别。关闭后直接 OCR，不删除或停用模型资源；筛图不可用或失败时记录原因并继续识别。图片灯箱中手动发起的文字识别不受影响。
- 好友克隆从消息列表「+」创建；打开克隆体会话的「设置」可管理聊天模型、生成参数、额外提示、发言意愿、错别字、语音及记忆，并更新画像或删除克隆体。全局设置不再单列克隆页，训练时的检索与视觉模型保留原绑定，不直接替换已有向量。
- 「互动画像」独立启用，管理统计范围、采样与推断方式，可仅做本地统计，或选择本地／独立 API 模型；旧「跟随意图感知」在迁移时固定为当时选择，之后分别保存。
- 本地文字识别增强包一起准备 OCR 与小型筛图模型，无需单独选用。图片灯箱和导出可复用；在线失败时能否本地回退取决于平台和完整的模型／引擎资源，不支持的平台会明确提示。
- QQ 在线 OCR 是 QQ 服务端能力，不是本地模型；不需要下载本地模型，但需要 QQ 在线及对应凭据。
- 「API 用量」按功能及服务商／模型显示当前账号与应用全局请求，可切换近 24 小时、近 7 天、近 30 天和全部保留记录。24 小时包含当前小时，7／30 天包含今天，均按北京时间统计；趋势可切换已知 token 与请求次数，查看全部保留记录时趋势仍展示最近 30 天。
- 账号账本与应用全局账本各保留最近 5000 条请求，页面显示保留数量、最早记录与达到上限的提示；总量不是无限期历史累计。全局请求包括模型连接／能力检测与语音服务，切换账号后仍会显示同一份全局记录。
- 用量只取 API 实际返回值，未返回的总量或输入／输出分项分别标为未知，不按零或字符数估算，也不换算费用。本地推理不计入。失败、取消、进行中和中断分别统计，实际重试各算一次请求。新请求保留调用时的服务商配置身份，旧记录缺少的归属显示为未知；同名模型及同名配置不会因此合并。克隆体明细按需展开，已删除克隆的用量仍保留。

模型资源与旧配置迁移见[模型设置](model-resources.md)。

## 服务与更新

- [MCP](mcp-server.md)让外部客户端访问当前账号能力，注意工具的读写范围。
- 外部 RKEY 配置在本机在线凭据不可用时补充媒体下载票据；测试只验证连通性，不保证所有媒体仍可下载。
- SSE 向配置目标发送消息事件，测试按钮会真实发送测试事件。地址与 token 属于敏感配置。
- 外部 RKEY 与 SSE 测试也使用后台横幅；切换编辑目标不会把前一配置的迟到结果写进当前表单。
- QQ 公众号推送位于「WeQ 服务」的独立二级页，沿用既有开关与端口，资源只在 WeQ 运行期间提供；完全退出后不再提供新请求，QQ 已缓存的内容可能仍显示。版本检查复用应用内更新，不再提供退出后的独立版本轮询。
- 各服务的运行状态、地址、开关与端口在各自的管理页查看和配置。
- “关于 WeQ”分为「版本与更新」「配置备份与恢复」「常见问题」「日志与性能」「反馈」。日志与性能页用两张卡片集中提供自动保存的性能记录档位、完整记录时长、历史保存策略，以及日志保留时长、原生调试日志和日志文件夹入口；性能监视和日志查看分别使用较小的独立窗口，可同时打开。历史保存策略仅在确实会删除现有记录时确认，并列出当前占用、新容量／回收目标或清理截止时间；无删除影响时直接保存，清空历史仍需确认。旧日志与性能监视链接均定位新设置页，不自动打开窗口。旧帮助入口转到常见问题，旧更新提醒入口转到版本与更新。Web 不提供桌面应用自替换；原生组件兼容或过期问题以当前界面提示处理。
- 日志窗口隐藏时停止读取，返回后保留所选文件、等级筛选、暂停跟随和滚动位置，并补读离开期间新增的内容；文件被截断时重新载入，不擅自恢复跟随。暂停跟随只暂停自动滚到最新位置，不代表停止读取文件。跟随当前 WeQ 日志时会在它轮转后切到新分段，主动选中的历史日志不自动切换。已封闭的分段会自动压缩，仍可在窗口内查看，和明文采用相同的日志保留时长。更多见[性能监视](performance-monitor.md)。
- 手动下载 WeQ 更新时，更新卡片显示进度，提供暂停、继续和失败重试。点「后台进行」可将同一次下载交给任务列表。下载完成后可点击「重启并安装」，安装退出不受“关闭时询问／最小化到托盘”偏好拦截。按钮会显示「正在重启」并避免重复提交，安装失败后可直接重试安装。开发版仍只支持检查更新。
- 「版本与更新 → 软件更新」可设置自动检查更新频率，单位为分钟，默认 60，正数不设上限（支持小数），`-1` 表示永不。保存后立即重新计时；安装版启动后仍会延迟检查一次，设为 `-1` 时也关闭启动检查，手动检查不受影响。开发版不自动检查。
