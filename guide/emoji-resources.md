# 表情与装扮资源

普通模式完全隐藏个性装扮页及其导航、搜索入口，不恢复此前打开的装扮页面；保留聊天记录中原有的气泡、字体、挂件和表情显示，以及已有自定义聊天背景。装扮页面、任意装扮安装覆盖、独立素材保存与商城表情整包解密仅在[开发运行环境显式开启装扮工具](../develop/dev-startup.md)后开放。以下商城操作说明适用于已开启该工具的开发环境；本地已缓存表情的资源浏览不受影响。

装扮离线索引在「设置 → 增强功能 → 增强包」准备，不随安装包携带，普通装扮浏览不触发整类索引下载。它与其他增强包统一检查和更新，默认自动检查、手动安装；任务列表显示进度、暂停和重试，下载遵循省流量设置。已缓存装扮仍直接使用，各账号及连接同一宿主的 Web／Remote 共用缓存。索引只提供素材地址，完全断网时只能使用本机已有素材；新索引还须匹配 native 密钥来源。

## 商城表情

从左栏 **个性装扮 → 商城表情** 页签进入内容页，不需要先打开旧本地资源浏览器。

- 页签工具栏左侧按免费、付费、VIP、SVIP 等条件筛选，右侧提供多选和搜索。输入表情包名称后回车搜索，清空恢复目录。目录搜索离线可用。
- 选择表情包查看名称、介绍及解密图片；离线目录不代表图片已经下载或在线商城完整历史。
- 批量下载保留原有任务与保存流程；单张预览失败不视为已取得资源。
- 商城目录、QQ 已下载贴纸和个人自定义表情是不同来源，不混算数量。
- 目录与其他装扮页一样使用卡片网格，卡片展示首张表情预览；接近可视区域时才加载，失败时保留占位。点击查看整包，返回后保留目录位置。
- 页面跟随装扮页的深浅模式、主题色与界面背景。

## 自定义与聊天表情

聊天中的系统表情和贴纸由消息渲染器显示，点击可查看可用预览。QQ 资源目录缺失时，联网补全仍受当前凭据和资源可用性限制。

聊天输入框的表情面板中，**收藏**显示 QQ 的收藏表情，不是左栏的消息收藏。选择后先加入草稿，
可与文字一起发送。面板使用缩略图，发送使用对应原图，GIF 保留动画；原图不在本机时尝试读取
收藏记录中的在线原图。无法取得原图时明确失败，不改发静态缩略图，也不自动重发。
单张原图上限为 20 MiB，同条消息不同收藏资源合计上限为 40 MiB；超出时请分开发送。

从 WeQ 添加的收藏会保留原图缓存，添加后即可在面板选取发送，无需等待 QQ 本地同步；重新打开仍可使用。QQ 后续同步同图时不会重复显示，删除收藏时同步清理对应的 WeQ 原图缓存。

管理 QQ 收藏表情可进入 **设置 → 凭据与数据 → QQ 资源管理 → 资源浏览 → 自定义表情 → 收藏表情**。
添加入口在列表工具栏，备注编辑、上移、下移和删除在每行的操作菜单中，也可右键该行。
编辑器在原行展开，取消未保存修改会确认；切换到“收到的表情”或“我的表情”不会丢掉当前草稿，
切换账号或数据源则清理旧来源的编辑状态。在线操作仍需当前 QQ 连接，未确认回执保留编辑内容。

导出个人表情从统一工具选择[导出表情包](export.md#11-导出表情包)，区分“我的表情”和“收到的表情”、原图与缩略图。QQ 缓存占用与清理由 **设置 → 凭据与数据 → QQ 资源管理** 管理；WeQ 自身缓存位于「关于 WeQ → WeQ 存储管理」。

需要研究缓存格式时，参见[表情数据库](../database/emoji.md)和[商城表情解密](../develop/principles/mface-decrypt.md)，不要把磁盘布局当使用步骤。

## 个性装扮

左栏 **个性装扮** 打开主内容整页。首次进入时显示第一个页签 **聊天气泡**，再次打开时恢复上次浏览的页签、筛选和列表滚动位置。最右侧的 **使用中** 页签有六张卡片，展示气泡、字体、头像挂件、通话背景、聊天背景和浮屏挂件的全局默认值，可在卡片上取消使用或进入对应类别更换。

通过主导航离开个性装扮。单栏布局也支持用系统返回回到原页面。

- 聊天气泡、聊天字体、头像挂件和通话背景可在页签工具栏切换 **热门** 与 **已装**，也可在右侧按名称搜索。热门可离线浏览，商城搜索需要登录 QQ，已装搜索可离线使用。
- “已装”显示本地安装及可确认的 QQ 当前装扮；点击 **使用** 安装并在 WeQ 本地生效，失败会提示。**不修改 QQ 装扮设置，也不影响实际发送的消息装扮**；发送字体由聊天消息的发送设置决定。
- 装扮可在卡片上单项下载，也可从工具栏进入 **多选** 后下载所选款式。保存方式为「开始前选择」时，先选文件夹再创建下载任务。单项保留实际资源格式，多款打包为 ZIP，未下载成功的款式显示在任务详情中。Web 可从任务列表下载完成的文件。
- 气泡、字体和挂件默认不启用本地覆盖，按消息记录还原；启动同步 QQ 装扮只准备资源，不自动使用或启用 QQ 同款背景。旧版保存的消息覆盖选择恢复为不使用，已装资源和背景选择保留，需要时重新点击 **使用**，此后会记住明确选择。
- 气泡、字体和头像挂件在各自卡片上分段选择 **渲染范围**，可预选，选用装扮后生效。**仅自己** 只覆盖自己发出的消息；**替代无装扮** 对自己和他人的消息，仅替代原本没有对应装扮的部分；**覆盖全部** 统一覆盖自己和他人的对应装扮。已有装扮尚未加载或加载失败不视为无装扮。升级时将原共用范围沿用到三项。
- “使用”仅影响 WeQ 本地显示，不影响实际发送；这项说明集中显示在 **使用中** 页签，商城卡片仍可直接使用与下载。
- 聊天背景可关闭、使用 QQ 同款，或用 **自定义** 预览中央的按钮选择或更换图片或视频。启用聊天背景或浮屏挂件后，可在 **使用中** 对应卡片或 **聊天背景** 页签分别调节不透明度。拖动实时预览，松手后保存。
- 在私聊或群聊的 **会话设置 → 装扮** 中，可对聊天背景和浮屏挂件分别选择 **跟随全局**、**单独选择** 或 **不使用**。单独选择的背景和挂件可在该会话中调节不透明度。开发装扮模式下，支持通话的私聊也可单独设置通话背景。
- **使用中** 对应卡片的「会话单独设置」列出单独选款及明确关闭的会话。展开后点会话名可直达该会话的装扮设置。
- 红包封面可在页签内按名称搜索。点开卡片即可放大卡片上的同一张封面图。
- 本地背景不使用商城搜索，相关筛选在该类别隐藏。聊天中的逐条装扮渲染另受[消息阅读设置](settings.md#主题与聊天显示)控制。
