# 防撤回

WeQ 可以保存撤回前的原文，也可以通过代理或数据库触发器让本机 QQ 保留原文。

## 1. 打开位置

**菜单 → 设置 → 基础功能 → 互动与防撤回 → 防撤回**。菜单里的防撤回快捷入口也定位到同一分区，不再占用单独的二级设置页。

设置页直接显示保护范围、触发器状态和保护会话摘要。点击「编辑会话」修改保护名单，点击「选择提醒会话」修改通知名单，点击「查看撤回记录」打开按会话汇总的目录。打开工具不会关闭设置或跳转页面。

单会话级别的开关在**会话头部顶栏的设置按钮**里（比照设置页的大窗口，左侧分类、右侧内容）：

| 分类 | 能做什么 |
| --- | --- |
| **防撤回** | 直接开关「保护此会话」与「本会话撤回提醒」，也可调整全局撤回通知方式 |
| **群关键词**（仅群聊） | 关键词 + 每个词的成员范围的完整编辑器，就地改、关窗即保存 |

单会话开关遵循全局防撤回方式和保护范围。防撤回关闭时，打开「保护此会话」会恢复上次方式，并把范围切到「指定会话」；选择「全部会话」时，所有会话均受保护。

## 2. 防撤回方式

四档纵向单选，标题下直接显示说明。

| 方式 | 说明 |
| --- | --- |
| 关闭 | 消息按 QQ 的正常流程撤回。 |
| 仅在 WeQ 中保留 | QQ 照常撤回。连接代理时实时留存；未连接时，仅保留 WeQ 及时读到的原文。 |
| 在 WeQ 和本机 QQ 中保留（代理拦截） | WeQ 运行且 QQ 连接代理时生效。 |
| 在 WeQ 和本机 QQ 中保留（数据库触发器拦截） | 无需代理。触发器生效后，关闭 WeQ 也会继续保护。 |

原有防撤回设置升级后沿用数据库触发器方式及原保护名单。关闭功能后，已有撤回记录仍可查看。

## 3. 保护范围

开启防撤回后，保护范围默认为「全部会话」，也可切换到「指定会话」。升级时沿用已保存的范围。切换方式、关闭功能或临时选择全部会话后，已选名单仍然保留。

「指定会话」提供全选、反选、清空和搜索。点击「编辑会话」打开名单工具，点击「保存选择」后生效。关闭尚未保存的工具时会确认是否放弃修改。名单按账号与数据源保存，防撤回方式为同一宿主各端共用的偏好。

## 4. 生效状态与原文留存

设置页显示当前来源的真实状态，包括正在应用规则、等待 QQ 连接代理、代理已连接、实际安装的触发器和应用失败原因。

选择「仅在 WeQ 中保留」或「在 WeQ 和本机 QQ 中保留（代理拦截）」后，可从防撤回设置直接打开 [QQ 代理连接](./settings.md#qq-代理连接)，查看连接状态、当前端口和设置步骤。原文及撤回通知先进入本机持久队列，WeQ 保存后再确认处理。代理方式按会话过滤实时撤回子消息，同一推送中的其他消息保持原始字段。WeQ 停止处理时，过滤租约到期后继续正常转发。

数据库触发器在 QQ 的 `nt_msg.db` 中阻止撤回改写原文。安装、卸载或修改范围后，如果 QQ 正在运行，状态区域会提示可能需要重启 QQ 后生效。静态 PC 来源是离线快照，无法接收新的撤回。

WeQ 独立原文副本按账号与数据源保存。未撤回快照保留七天、最多一万条；已撤回正文持久保留。未及时收到或读取的原文无法补回。图片、语音和文件记录保留资源信息，实际打开仍取决于本地媒体或下载来源是否可用。

## 5. 撤回通知

在会话设置的「防撤回」页，可以直接开关「本会话撤回提醒」，与统一设置共用同一份提醒名单，不改变保护范围。全局设为「不通知」时仍可保存本会话的选择；收到提醒还需要本会话受保护，且至少开启一个全局通知渠道。

在「常规 → 通知与提醒 → 其他通知」展开「撤回提醒」行，分别选择应用内横幅和系统通知；通过行旁的会话范围图标勾选提醒会话。也可在「基础功能 → 互动与防撤回」原地编辑同一份设置。默认仅开横幅、不选择任何会话，因此选定会话前不会通知。关闭渠道不清空名单，空名单不表示全部会话。保护范围决定哪些会话记录撤回；系统通知开启时，点通知会唤起窗口并跳到那条消息。

通知只对**本次运行中新出现的撤回**生效 —— 启动时的历史记录不会补弹。

## 6. 查看被拦下的撤回

已留存的原文在聊天中显示撤回标记，也可以集中查看。

在 WeQ 中撤回自己发送的消息时，即使 QQ 尚未保存原文，也会在服务端确认撤回成功后保护 WeQ 已保存的发送缓存，并显示撤回标记。撤回列表和目录同时包含这部分记录；该保护遵循启用范围和会话清单，不会阻止服务端撤回，也不会让对方继续看到消息。撤回失败不记为已撤回。

- **设置 → 基础功能 → 互动与防撤回 → 查看撤回记录**：按会话汇总目录（条数 + 最近一次撤回时间），点一行在同一工具中查看消息，可返回目录；
- 打开对应会话，选择「消息 → 已撤回消息」（详见[消息编辑与删除](message-edit.md)）；
- 聊天里被拦截的消息气泡上也会带撤回标记，管理员撤回他人消息时会显示撤回者昵称。

设置里的消息详情沿用聊天气泡，会话里的「已撤回消息」用单行摘要定位原消息。两处都支持撤回者、被撤回者和正文筛选，读取失败可重试。设置中返回目录会保留阅读位置，关闭工具后回到原设置入口。切换账号/数据源、锁屏或关闭后重开，不会接收旧请求的迟到结果。

## 7. 和「删除」的关系

WeQ 自己的「删除消息」走的是和 QQ 撤回一样的机制（原地改写行 + 半透明覆盖），因此：

- **已删除消息**区分 WeQ 删除和 QQ 删除，只有前者可恢复；
- **已撤回消息**列出 WeQ 保留的撤回记录，不需要恢复。
